Panduan Penggunaan & Distribusi

Halaman ini adalah file HTML tunggal (tanpa server/database). Semua data KBLI dasar sudah tertanam di dalam file. Data perusahaan (KBLI aktif, pengurus, akta) disimpan di browser masing-masing perangkat.

Cara kerja penyimpanan

  • Setiap kali Anda menambah/mengubah data di tab "Data Perusahaan" atau "Kelola Perusahaan", data otomatis tersimpan di browser perangkat ini (localStorage).
  • Data ini tidak otomatis tersinkron ke perangkat/karyawan lain, karena file ini tidak terhubung ke server pusat.

Cara membagikan data terbaru ke karyawan (disarankan)

  1. Sebagai admin, lakukan semua input/edit data di browser Anda.
  2. Klik "Ekspor Data Perusahaan (JSON)" — ini akan mengunduh file bernama kbli-company-data.json.
  3. Letakkan file kbli-company-data.json tersebut di folder/lokasi jaringan (mis. intranet, shared drive) yang sama persis dengan file HTML ini.
  4. Bagikan tautan/folder tersebut ke karyawan. Saat karyawan membuka file HTML untuk pertama kali (belum ada data tersimpan di browser mereka), aplikasi akan otomatis memuat data dari kbli-company-data.json.
  5. Jika Anda memperbarui data lagi di kemudian hari, ulangi ekspor & ganti file kbli-company-data.json di lokasi bersama itu, lalu minta karyawan menekan tombol "Muat Ulang dari File Pusat" untuk menyegarkan data di browser mereka.

Alternatif tanpa jaringan bersama

  • Ekspor file JSON dan kirim manual (email/chat) ke karyawan terkait, lalu mereka membuka tab "Data & Panduan" → "Impor Data dari File" dan memilih file tersebut.

Catatan penting

  • Data KBLI 2020 ↔ 2025 dasar (padanan resmi) tidak bisa diedit dari antarmuka ini karena bersumber dari data resmi yang Anda unggah — hanya penandaan "perusahaan mana yang memakai kode ini" serta data pengurus/akta yang bisa diedit.
  • Selalu simpan salinan cadangan file JSON secara berkala.
